# Windows Forensics Project

## Overview

This project focuses on Windows forensic analysis in a controlled lab environment.

The project includes evidence collection, artifact analysis, memory/file investigation, and structured reporting.

## Main Objectives

- Collect and analyze forensic artifacts
- Investigate files, processes, and system indicators
- Use forensic tools to extract useful evidence
- Document the investigation process and findings
- Practice structured forensic reporting

## Tools and Technologies

- Linux
- Bash
- Volatility
- Strings
- ExifTool
- Foremost
- Bulk Extractor
- Command-line tools

## Files

- `windows_forensics.sh` - Project script
- `windows_forensics_report.pdf` - Full project report with explanations and screenshots

## Notes

This project was performed only in an authorized lab environment for educational purposes.
