# Cybersecurity Portfolio

###### 

### This repository contains cybersecurity projects completed as part of my Cyber Defense and Information Security training.

#### 

#### Each project includes:

#### 

##### Source code

##### A PDF report

##### Technical explanation and methodology

##### Lab-based screenshots and results

#### 

### Projects

#### 

#### 1\. Network Research

#### 

##### A networking research project focused on host discovery, protocol understanding, network behavior, scanning results, and technical documentation.

#### 

#### 2\. Windows Forensics

#### 

##### A Windows forensics project focused on evidence collection, memory and file analysis, artifact extraction, and structured forensic reporting.

#### 

#### 3\. Penetration Testing

#### 

##### A Bash-based penetration testing automation project for authorized lab environments, including scanning, service detection, login service identification, optional weak credential testing, and vulnerability mapping.

#### 

#### 4\. Domain Mapper

#### 

##### A modular Bash-based network reconnaissance tool designed for automated host discovery, service enumeration, network analysis, and report generation. The project supports multiple scanning levels and produces structured reports for network assessment.

##### 

#### 5\. Darknet Crawler

#### 

##### A Bash-based darknet crawler capable of accessing .onion websites through the Tor network. The project supports automated crawling, website indexing, title extraction, link discovery, keyword-based alert management, logging, and status monitoring.

#### 

#### 6\. Python Log Analyzer

#### 

##### A Python-based security tool for analyzing Linux auth.log files. The project detects sudo commands, failed sudo attempts, su activity, user creation and deletion, and password changes, and presents the results in a structured terminal report.

#### 

#### Disclaimer

#### 

##### All projects in this repository were created for educational purposes and authorized lab environments only. No unauthorized scanning, exploitation, or access was performed.
