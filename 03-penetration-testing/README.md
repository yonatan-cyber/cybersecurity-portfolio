# Penetration Testing Automation Project

## Overview

This project is a Bash-based automation script designed for controlled penetration testing in a private lab environment.

The script automates several stages of a basic penetration testing workflow, including scanning, service detection, login service identification, optional weak credential testing, and vulnerability mapping.

## Main Features

- Private IP range validation
- TCP and UDP scanning
- Service and version detection
- Login service identification
- Optional weak password testing
- Nmap NSE vulnerability scan
- Searchsploit mapping
- Organized output folder and report files

## Tools and Technologies

- Bash
- Nmap
- Hydra
- Medusa
- Searchsploit
- Linux CLI tools

## Files

- `penetration_testing_automation.sh` - Main automation script
- `penetration_testing_report.pdf` - Full project report with explanations and screenshots

## Safety Notice

This project is for educational and authorized lab use only.
Do not run this script against systems you do not own or do not have permission to test.
