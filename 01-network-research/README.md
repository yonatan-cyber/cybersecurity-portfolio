# Network Research Project

## Overview

This project focuses on network research and analysis in a controlled lab environment.

The goal of the project was to understand network behavior, identify active hosts and services, analyze network information, and document the results in a clear technical report.

## Main Objectives

- Perform network research and reconnaissance in a lab environment
- Identify hosts, services, ports, and protocols
- Analyze scan results and network behavior
- Document findings in a structured PDF report
- Practice technical reporting and command-line workflow

## Tools and Technologies

- Linux
- Bash
- Nmap
- Wireshark
- Network protocols
- Command-line tools

## Files

- `network_research.sh` - Project script
- `network_research_report.pdf` - Full project report with explanations and screenshots

## Notes

This project was performed only in an authorized private lab environment.
